# Stitch visual implementation

Source project: https://stitch.withgoogle.com/projects/14138619381293668352

The visual layer in `stitch.css` was implemented from the user-provided Stitch export.

## Applied system

- warm paper background: `#FAF9F4` / `#F5F4EF`
- charcoal structural UI: `#30312E`
- primary lime action: `#D7F85E`
- tactile keys with a crisp 2px mechanical shadow
- recessed paper-like result display
- paper-tape calculation history cards
- two-column calculation-note workspace on desktop
- compact single-column calculator on mobile
- dark mode adapted from the same neutral/lime palette

The calculation engine, history storage, notes data model, sharing/export behavior and PWA remain implemented by the existing application code.
