## 실제 브라우저 확인

| 화면 | 펼친 하단 높이 | 접힌 하단 높이 | 광고 실측 폭 | 결과 |
| --- | --- | --- | --- | --- |
| PC 1440×635 | 170px | 45px | 320px | 본문 하단과 광고 상단 일치, 겹침 없음 |
| 모바일 390×844 | 170px | 45px | 320px | 본문 높이 674px → 799px, 가로 넘침 없음 |
| 모바일 320×740 | 170px | 45px | 320px | 광고 좌우가 0~320px, 잘림·가로 넘침 없음 |

- 실제 Kakao SDK가 카카오비즈니스 배너를 반환하는 것을 확인했다.
- 첫 요청 후 접기·펼치기·계산노트 전환에서 같은 iframe ID와 SDK 1개·ins 1개 유지.
- 계산식 포커스 후 자동 접힘, 계산노트 전환 후 접힘 유지 확인.
- 접힌 상태에서 새로고침 후 SDK 0개·ins 0개: 사용자가 펼치기 전 요청하지 않음.
- 광고와 본문은 겹치지 않으며 숫자판은 본문 스크롤 안에서 접근 가능.
- 브라우저 오류 로그 없음. 기존 계산식·기록·노트 내용을 수정하거나 지우지 않고 검증했다.
- 임시 모바일 화면 크기 설정은 검증 후 원래대로 복구했다.

## 관리자 확인

계산기 전용 광고단위는 정상이며, 소재 새로고침은 60초에서 미설정으로 변경했다. **calc 계산기 매체는 심사 대기**다. 카카오 기본 배너 수신과 상용 광고 심사 승인은 구분하며, 이번 검증은 승인 또는 광고 수익 발생을 뜻하지 않는다.
